# Coffee Brew Dialer

iPhoneのSafariで使うことを前提にした、コーヒー抽出のダイヤルイン支援PWAです。

## v0.2 の主な機能

- 基準レシピを複数保存・切替
- 豆・焙煎度・抽出器具・グラインダーの設定
- 豆量 / 湯量 / 湯温 / 挽き目 / 抽出時間の記録
- 抽出比率の自動計算
- 好み（甘さ・香り・すっきり感・コク・酸味・苦味）の保存
- 原則「1変数だけ」変更する次回提案
- 工程ごとの抽出タイマー
- 注湯ステップの編集
- 苦味・酸味・甘味・コク・香りの評価
- 実測の注ぎ終わり / 落ち切り時間の保存
- 抽出履歴を端末内（localStorage）に保存
- オフライン対応のService Worker

## 登録済み基準レシピ

### 深煎りコロンビア × ロクサン

- 豆: コロンビア 深煎り
- 器具: ロクサン ステンレスフィルター
- グラインダー: TIMEMORE C5 Pro 25
- 豆量: 10g
- 湯量: 260g
- 湯温: 93℃
- 注ぎ終わり: 2:00
- 落ち切り: 2:18

### グァテマラ × HARIO Switch × C5 Pro 25

中煎りを想定した開始点です。

- 豆: グァテマラ
- 器具: HARIO Switch
- グラインダー: TIMEMORE C5 Pro 25
- 豆量: 15g
- 湯量: 250g
- 湯温: 92℃
- Switch OPENで40g蒸らし
- 0:30に120gまで透過
- 0:45にSwitch CLOSE
- 0:50から250gまで注湯
- 1:45にSwitch OPEN
- 2:45前後を落ち切り目安

この値は固定の正解ではなく、味の評価から1変数ずつ調整するための基準です。
