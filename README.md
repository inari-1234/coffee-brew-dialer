# Coffee Brew Dialer

iPhoneのSafariで使うことを前提にした、コーヒー抽出のダイヤルイン支援PWAです。

## v0.1 の主な機能

- 豆・焙煎度・抽出器具・グラインダーの設定
- 豆量 / 湯量 / 湯温 / 挽き目 / 抽出時間の記録
- 抽出比率の自動計算
- 好み（甘さ・香り・すっきり感・コク・酸味・苦味）の保存
- 原則「1変数だけ」変更する次回提案
- 工程ごとの抽出タイマー
- 注湯ステップの編集
- 苦味・酸味・甘味・コク・香りの評価
- 実測の注ぎ終わり / 落ち切り時間の保存
- 抽出履歴を端末内（localStorage）に保存
- オフライン対応のService Worker

## 初期基準レシピ

今回の実測を初期値にしています。

- 豆: コロンビア 深煎り
- 器具: ロクサン ステンレスフィルター
- グラインダー: TIMEMORE C5 Pro
- 豆量: 10g
- 湯量: 260g
- 挽き目: 25
- 湯温: 93℃
- 注ぎ終わり: 2:00
- 落ち切り: 2:18

## GitHub Pages

Repository Settings → Pages で `main` / `/(root)` を公開対象にすると、SafariからURLを開いて利用できます。
